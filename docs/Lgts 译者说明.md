# 《Little Goody Two Shoes》汉化双语译本 — 译者说明

## 一、角色名、昵称与错叫名

> **统计口径**：本节所标"处数"按 v1.3.27 译本统计，口径为「`英文原文` 含该词的记录行数」（正则 `\b词\b`，区分大小写）。数字随译本更新会变化，核对时直接在译本 CSV 里筛 `英文原文` 即可，不要以本文数字为准。

### 1. Rozenmarine / Rosmarine

- 真名 **Rozenmarine** 统一译「萝森玛琳」（109 处）。
- 伊莉丝和村民总把她名字念成 **Rosmarine**（贴近英语 rosemary，迷迭香）。错叫名统一译「萝丝玛琳」（711 处），和真名保持听感反差。她本人小声纠正、没人听，是贯穿全剧的梗（见 `CUT_2_5_HLR_01_043`「是萝森玛琳啦……」、`CUT_3_3_VIN_01_003`「我、我叫萝——森——玛琳！」）。

### 2. Lebkuchen / Leb / lebkuchen

- 真名 **Lebkuchen** 统一译 **「斯佩尔特」**（430 处），作角色名出现在名牌、旁白、任务提示里。
- 昵称 **Leb**（138 处）从「斯**佩**尔特」取音节，作叠字 **「佩佩」**。
- **同名食品另算**：`ITM_F_N_08` 这件道具（德式蜂蜜姜饼）英文也是 `Lebkuchen`，译 **「姜饼」**；台词里另外 5 处 `lebkuchen`（`CUT_4_2_VSQ_01_021/031/041`、`DLG_5_3_VSQ_04_002/014`）同样译「姜饼」。
- 所以 `Lebkuchen` 是**同形异义**：`display` 与 AT 的裸键取名「斯佩尔特」，`lgts_item_names.json` 与 `ITM_F_N_08` 取食名「姜饼」。两个工具脚本里写死了 `NAME_OVERRIDE` 守住这条界线——不要靠手改 JSON 修，重建会按脚本规则重写。

### 3. Muffy 的 14 种错叫名

- 真名 **「穆菲」**，全镇大人几乎没叫对过，原文有 14 种 `M-` 开头的错叫。
- 错叫名必须一对一音译：早期译法撞过字（`Macy` 和 `Mercy` 同译、`Mindy` 串成梅莉），也有人泛化成"那丫头"，这样她后面的抗议「我、我是穆菲！你们怎么就没一个人叫对过我的名字！」就没了着落。

| 英文原名 / 错叫名 | 汉化定名 | 说明 |
| :--- | :--- | :--- |
| **Muffy** | **穆菲** | 真名，仅本人抗议正名等极少数情况出现 |
| **Muffs** | **穆芙丝** | 伊莉丝用的西式谐音绰号，不译"小穆" |
| **Mubby / Muddy** | **穆比 / 穆迪** | 含 muddy（泥巴）的戏谑联想 |
| **Miffy / Milly / Missy** | **米菲 / 米莉 / 米茜** | 高频前元音错叫；`Missy` 兼有"小丫头"意，译「米茜」衔接正名 |
| **Mindy / Mandy** | **明蒂 / 曼迪** | 罗蕾莱太太和镇民常用 |
| **Molly / Melly / Merry** | **莫莉 / 梅莉 / 麦莉** | 鼻音、边音相近，「梅莉」「麦莉」严格区分 |
| **Macy / Mercy / Maggie** | **梅西 / 默茜 / 玛姬** | 散见 M 头女名，「梅西」「默茜」严格区分 |

### 4. Welma / Wilma

- 两个名字只差一个字母，但是两个人：
  - **Wilma**（226 处）是旅店老板娘，脾气难缠的老太太，译 **「威尔玛」**。
  - **Welma**（26 处）是从普里梅尔多夫来、在旅店卖货的年轻姑娘，译 **「薇尔玛」**，和补丁里她的名牌一致。
- 敬称照原文：原文带 Mrs. / Miss 才加 **「威尔玛太太」**、**「薇尔玛小姐」**，直呼其名就不加。
- 早期把 Welma 当成 Wilma 的拼写异体，两人都译成「威尔玛」，只靠「太太/小姐」区分。原文直呼其名时读者就分不清是谁：`DLG_4_2_VIN_04_004` 是威尔玛自己说「今晚我得让薇尔玛把我旅店里每一扇窗都锁上」，旧译作「让威尔玛」，读起来像在说她自己。收官时已改正。

## 二、双关

### 1. `in your shoes` —— 红鞋双关

- 习语意思是"处在某人的境地"，但这里同时指伊莉丝脚上那双象征欲望和诅咒的红鞋（Goody Two Shoes）。只译"境地"，后面的台词"你不明白这双鞋意味着什么"就没了字面抓手。
- 译法：**「穿着你脚上那双鞋，走在你如今的路上」**，习语义和红鞋实物一起保留。

### 2. `Gifts` / `gifted` —— 祭礼专名与反讽

- 献给森林神明（**祂**）的三样祭品统一叫 **「赠礼」**（Gifts）；试炼所得叫 **「信物」**（Testaments）。三要素：**「鲜嫩的血肉」**（Tender Flesh）、**「最甜美的琼浆」**（Sweetest Nectar）、**「良伴」**（Good Company）。
- `DLG_4_5_WCR_C_05_031~033` 中，乌鸦把红鞋和邪咒说成神的赐予，译 **「是祂*赐予*你的『赠礼』！」**，保留反讽。

### 3. 其余局部双关

- **`song and dance`**（`DLG_3_2_OLH_01_014~015`）：字面"歌舞"+习语"敷衍戏码"，两处分别译 **「载歌载舞的热闹戏码」** 和伊莉丝内心冷嘲 **「（载歌载舞的敷衍戏码……）」**。
- **`crowded trees`**（`DLG_4_5_WCR_A_04_010`）：乌鸦（crow）盘踞的密林，译 **「黑鸦鸦的密林」**。
- **`coming around`**（`CUT_3_2_VIN_01_024~025`）："想通"和"转去赴约"双关，译 **「既不会*转过弯来*，也不想*转去那儿*」**。另一分支 `036~041` 同样用「转过弯来 → 说到转弯 → 拐到水井那边」接住这个双关。

## 三、民俗考据与语体

1. **`hag-ridden`**：民间传说女巫（hag / Mare）夜入马厩，骑马狂奔一整夜，还在马鬃上打结（Witch's stirrups）。第四章马夜里累垮、鬃毛被编成辫子，不泛化成"中邪"，统一译 **「遭了女巫夜骑的魔祟」**。
2. **神明代词「祂」**：指森林神明（Ozzy）和天主的大写 `He / Him / His` 统一用 **「祂」**；女巫结社 `covenant` 译 **「巫会」**，和教堂经文的语体区分开。
3. **乡土口语**：年长女性的 `lass / lassie / dearie` 按角色分 **「丫头 / 小丫头 / 乖丫头」**；男童 `lads / laddies` 译 **「小子们」**；骂鸟的 `feathered rat` 译 **「长羽毛的耗子」**（可加修饰，如「长着羽毛的讨厌耗子」）。
4. **内心独白**：伊莉丝括号独白句尾的 `, huh...` 不做机械反问，统一转成 **「……呢…… / ……啊……」** 的自言自语口吻。

- 源文笔误：`DLG_2_3_VSQ_03_021`（Kieferberg → 普里梅尔多夫）、`CHR_009_036`（Mr. Wilhelm → 欧根先生）按上下文修复，备注写「源文修复」；`TASK_LUDWIG_CHICKENS`（键名是喂鸡、英文是摘苹果）和 `CHR_009_047`（欧根的差事里骂 old hag）没改。

## 四、人称与敬语的层次（您／你）

本译本把「您／你」当**情绪温度与社交距离**的轴来用。它既不是「见长辈用您、见平辈用你」的机械礼貌规则，也不是「一场对峙里一律用你」。判断某处对不对，要按整场的气温走，不能按行数投票。

### 1. 轴线

先有默认值，再谈叠加：

- 对**长辈、神父、店主**（莉丝贝特太太、格蕾特奶奶、汉斯神父、威尔玛……），默认就用「您」，亲疏不改变这一点。
- 对**同辈、晚辈、表妹、孩子**，默认用「你」。
- 下表是在默认值**之上**的叠加含义。

| 代词 | 叠加含义 |
| :--- | :--- |
| **您** | 冷、隔、拒。生分、端着、讽刺性的客气；冲突之后**用敬语把对方推开**；恐惧造成的距离（`DLG_3_2_OLH_02_001`「呀！**您**、**您**好，太太！」——莫莉把伊莉丝误当成长辈） |
| **你** | 热、撕破、发作；对默认用「您」的对象转「你」，就是降格或翻脸 |

**称谓不是判据。** 「太太／先生／神父」可以和「你」连用：`DLG_4_2_VBA_01_036`「这就是**你**的解决办法吗，奥蒂莉太太？」、`DLG_5_4_VCH_01_029`「这事儿压根轮不到**你**管，神父！」。带称谓不等于该用「您」。

### 2. 三段式弧线（范本：`DLG_4_4_VIN_01`，伊莉丝 → 奥蒂莉太太）

| 阶段 | 记录键 | 译文 |
| :--- | :--- | :--- |
| ① 克制 | `DLG_4_4_VIN_01_015` | **您**最好赶紧祈祷去吧！ |
| ① 克制 | `DLG_4_4_VIN_01_016` | **您**要是能克制一下自己，对**您**可大有好处，奥蒂莉太太。 |
| ① 克制 | `DLG_4_4_VIN_01_019` | **您**想说什么，奥蒂莉太太？ |
| ② 撕破 | `DLG_4_4_VIN_01_029` | 那就来吧！你想说什么就说什么吧，你这老巫婆！ |
| ② 撕破 | `DLG_4_4_VIN_01_050` | **你**听听自己说的这是什么话，奥蒂莉太太？ |
| ② 撕破 | `DLG_4_4_VIN_01_052` | **你**说，这有什么好处呢？ |
| ② 撕破 | `DLG_4_4_VIN_01_054` | 我表妹不过是帮**你**解决你自己的烦心事，你就这么报答她？ |
| ③ 收势 | `DLG_4_4_VIN_01_060` | **您**该别再自寻烦恼了，奥蒂莉太太。 |

③ 的触发写在原文里：对面先退让（`_053`「可我只是……」、`_055`「我不是有意要惹麻烦的，奥蒂莉太太……」），旁人再劝架（`_057`「我看啊，还是冷静点为好」、`_058`「或许该去找汉斯神父谈谈」）。此时换回「您」不是漏改，是把对方重新推回客气的距离外。

### 3. 同一笔法的其他实例

- **`DLG_4_5_VIN_01`**（伊莉丝 → 威尔玛）：`_032`／`_033` 用「你」→ `_034` 威尔玛退让「我确实不愿意，没错。」→ `_035`「但那不代表**您**就有权指控我表妹搞巫术。」
- **`DLG_5_4_VCH_01`**（伊莉丝 → 汉斯神父）：`_018` 客气收场「既然如此，那我们就谈到这儿吧，神父。」→ `_024`／`_029` 发作「**你**到底想从我这儿得到什么，神父——一场忏悔吗？」→ `_032` 用**同一句客气话**再收一次。
- **`DLG_2_3_VIN_01`**（伊莉丝 → 威尔玛）：整场被数落、忍到 `_039` 才撕破「不，你这个<i>傻老太婆</i>！」→ 收尾 `_050`「祝**您**愉快，威尔玛太太。」把门关上。
- **`DLG_5_2_VIN_03`**（伊莉丝 → 贝尔塔）：`_036` 被指控「你和你表妹……！」→ `_037` 冷嘲「<b>女巫</b>？**您**是想说这个吧？」——发作中反手一句敬语。
- **`DLG_4_3_VSQ_03`**（伊莉丝 → 威尔玛）：`_025` 用「您」配「母夜叉」（「整个基弗伯格都得围着**您**这么个母夜叉转！」），`_036` 起才转「你」正面开战。
- **`CHR_011`**（伊莉丝 → 威尔玛）：`_003` 硬顶「**你**凭什么觉得我会去呢」→ `_006`／`_010`／`_015` 改口答应，全用讽刺性敬语「免得**您**还得亲自钻鸡舍」。
- **反向弧线 `DLG_3_2_OLH_02`**（莫莉 → 伊莉丝）：`_001` 惊恐中误认「呀！**您**、**您**好，太太！」→ `_008` 认出熟人「格蕾特奶奶每次都给我面、面包，**你**、**你**看嘛……」——「您」也能标恐惧造成的距离。

### 3.1 反例：不是每场都要收回敬语

`DLG_4_2_VBA_01`：伊莉丝与奥蒂莉彻底翻脸后（`_026`／`_036`／`_040` 全用「你」）**再没换回**「您」——她并不打算给对方留台阶。收不收，取决于人物此刻想不想留余地，不是场次的固定流程。

### 4. 审查备注里的标记

属于这套弧线的行，备注以 `[人称]` 开头并标明阶段（弧线①／②／③）。**这些行不要按「对峙／同辈语境用你」机械改。**

**体例已收敛为三种写法，不再写笼统理由**（2026-10-28 定稿）：

| 写法 | 用在 |
| :--- | :--- |
| `[人称] 弧线②撕破：对××破敬用「你」` | 对长辈、神父本该用「您」，因撕破／发作改「你」 |
| `[人称] 同辈互称：平辈直呼其名，用「你」` | 对象确实是同辈，默认就用「你」，不构成降格 |
| `[人称] 长辈对晚辈：××谢伊莉丝，用「你」` | 长辈对晚辈，默认用「你」 |

由于这套收敛，旧式的「同辈语境」「同辈对话」在全库已 **0 条**。**按「同辈」搜索会命中 23 行，那是有意保留的「同辈互称」标签，不是漏改**；查漏请直接搜「同辈语境」「同辈对话」。同理，`[人称]` 共 56 处（其中 39 行以 `[人称]` 打头），`[称谓]` 还剩 195 行，是尚未改写的旧标签——两者不是同一套，别按前缀数量对账。

写备注时注意两点：

1. **理由不要写成「同辈语境」，除非对象真是同辈。** 曾有一批备注把对**汉斯神父**、对**老约亨／威廉先生**（长辈）的「你」也写成「同辈语境」，例如 `DLG_5_4_VCH_01_024/029/037`、`CUT_4_5_OCR_02_342`、`CUT_7_3_VSQ_01_003`、`DLG_2_3_VST_06_011`、`DLG_5_4_VBA_01_027`，以及 `DLG_4_2_VBA_01_045`、`CHR_011_003`。这些「你」的成因是**撕破／发作**，不是同辈，理由写错会让后人对神父、对长辈的「您」一并开刀。**2026-10-28 已把这 9 条的理由统一改为 `[人称] 弧线②撕破`；同批还改掉了 `DLG_4_4_VIN_01_050/052/054` 三条同类备注（共 12 条）。晚间按新体例又把 36 条备注整批改写，其中 8 条原写「同辈语境」的对象实为长辈或神父（老约亨、贝尔塔太太、古斯塔夫先生、路德维希先生、奥蒂莉太太、威尔玛太太），据实改标「弧线②撕破」。** 以后新写的照此办理。
2. **别把备注贴在弧线的起手行上，也别把独白当对话。** `CHR_011_003`「你凭什么觉得我会去呢，威尔玛太太？」紧接三行之后（`_006`／`_010`／`_015`）就是讽刺性的「您」，只写「对峙用你」不看下文，会把这一整段弧线拉平（该条已改标 `弧线②撕破`）。`CHR_019_015` 是内心独白（「（这不就是你让我去干的事吗！）」），不是当面人称，备注已改为 `[人称] 内心独白，非当面人称，不构成「你」的切换`。

### 4.1 萝丝玛琳对长辈一律用「您」

萝森玛琳／萝丝玛琳对长辈（约亨、多萝特娅、奥蒂莉）一律用「您」，跨场无一例外。`DLG_3_3_VST_01_036/037` 是最后一处例外，2026-10-28 已由「你」改「您」。这条是**跨场一致性**要求，不是场内弧线；核对时按说话人整条线扫，不按场次扫。


### 5. 供后来者核对的三步

1. 按 `全局序号` 把整场读完，先还原说话人与听话人（CSV 没有说话人列，只能从内容推断：谁自称「我表妹」「我丈夫」、谁被叫名字、谁在接谁的话）。
2. 代词一变，先问三句：**换了听话人没有？换了情绪节拍没有？这个节拍该不该收？**
3. 真要全量扫，扫的是「同一人、同一对象、同一节拍内来回摇摆」，不是「这一行有没有『您』」。非遗留层含「您」的行共 597 行，绝大多数是日常敬语，不是待办。
