# 《Little Goody Two Shoes》汉化双语译本 — 译者说明

本说明对应 `Little_Goody_Two_Shoes_汉化_双语译本版本8.csv`（v8），全表共 21,210 条。v8 在 v7 基础上修订的 2,108 行，审查备注里都带有以 `[v8` 开头的标签（如 `[v8感叹词·Oh]`、`[v8术语·节庆]`），筛选「v8」即可逐条查看。

游戏有德奥乡村民俗底色、格林童话母题，以及大量错叫名梗和英德双关。处理规则如下。

## 一、角色名、昵称与错叫名

### 1. Rozenmarine / Rosmarine

- 真名 **Rozenmarine** 统一译「萝森玛琳」（83 处）。
- 伊莉丝和村民总把她名字念成 **Rosmarine**（贴近英语 rosemary，迷迭香）。错叫名统一译「萝丝玛琳」（593 处），和真名保持听感反差。她本人小声纠正、没人听，是贯穿全剧的梗（见 `CUT_2_5_HLR_01_043`「是萝森玛琳啦……」、`CUT_3_3_VIN_01_003`「我、我叫萝——森——玛琳！」）。

### 2. Lebkuchen / Leb / lebkuchen

- 昵称 **Leb**（102 处）从「斯**佩**尔特」取音节，作叠字 **「佩佩」**。

### 3. Muffy 的 14 种错叫名

- 真名 **「穆菲」**，全镇大人几乎没叫对过，原文有 14 种 `M-` 开头的错叫。
- 错叫名必须一对一音译：早期译法撞过字（`Macy` 和 `Mercy` 同译、`Mindy` 串成梅莉），也有人泛化成"那丫头"，这样她后面的抗议「我、我是穆菲！你们怎么就没一个人叫对过我的名字！」就没了着落。

| 英文原名 / 错叫名 | 汉化定名 | 说明 |
| :--- | :--- | :--- |
| **Muffy** | **穆菲** | 真名，仅本人抗议正名等极少数情况出现 |
| **Muffs** | **穆芙丝** | 伊莉丝用的西式谐音绰号，不译"小穆" |
| **Mubby / Muddy** | **穆比 / 穆迪** | 含 muddy（泥巴）的戏谑联想 |
| **Miffy / Milly / Missy** | **米菲 / 米莉 / 米茜** | 高频前元音错叫；`Missy` 兼有"小丫头"意，译「米茜」衔接正名 |
| **Mindy / Mandy** | **明蒂 / 曼迪** | 罗蕾莱太太和镇民常用 |
| **Molly / Melly / Merry** | **莫莉 / 梅莉 / 麦莉** | 鼻音、边音相近，「梅莉」「麦莉」严格区分 |
| **Macy / Mercy / Maggie** | **梅西 / 默茜 / 玛姬** | 散见 M 头女名，「梅西」「默茜」严格区分 |

### 4. Welma / Wilma

- 原文两种拼写并存：`Wilma`（159 处）、`Welma`（19 处）。人名统一 **「威尔玛」**；敬语按原文区分 **「威尔玛太太」** 与 **「威尔玛小姐」**，避免同句里辈分打架。

## 二、双关

### 1. `in your shoes` —— 红鞋双关

- 习语意思是"处在某人的境地"，但这里同时指伊莉丝脚上那双象征欲望和诅咒的红鞋（Goody Two Shoes）。只译"境地"，后面的台词"你不明白这双鞋意味着什么"就没了字面抓手。
- 译法：**「穿着你脚上那双鞋，走在你如今的路上」**，习语义和红鞋实物一起保留。

### 2. `Gifts` / `gifted` —— 祭礼专名与反讽

- 献给森林神明（**祂**）的三样祭品统一叫 **「赠礼」**（Gifts）；试炼所得叫 **「信物」**（Testaments）。三要素：**「鲜嫩的血肉」**（Tender Flesh）、**「最甜美的琼浆」**（Sweetest Nectar）、**「良伴」**（Good Company）。
- `DLG_4_5_WCR_C_05_031~033` 中，乌鸦把红鞋和邪咒说成神的赐予，译 **「是祂*赐予*你的『赠礼』！」**，保留反讽。

### 3. 其余局部双关

- **`song and dance`**（`DLG_3_2_OLH_01_014~015`）：字面"歌舞"+习语"敷衍戏码"，两处分别译 **「载歌载舞的热闹戏码」** 和伊莉丝内心冷嘲 **「（载歌载舞的敷衍戏码……）」**。
- **`crowded trees`**（`DLG_4_5_WCR_A_04_010`）：乌鸦（crow）盘踞的密林，译 **「黑鸦鸦的密林」**。
- **`coming around`**（`CUT_3_2_VIN_01_024~025`）："想通"和"转去赴约"双关，译 **「既不会*转过弯来*，也不想*转去那儿*」**。另一分支 `036~041` 同样用「转过弯来 → 说到转弯 → 拐到水井那边」接住这个双关。

## 三、民俗考据与语体

1. **`hag-ridden`**：民间传说女巫（hag / Mare）夜入马厩，骑马狂奔一整夜，还在马鬃上打结（Witch's stirrups）。第四章马夜里累垮、鬃毛被编成辫子，不泛化成"中邪"，统一译 **「遭了女巫夜骑的魔祟」**。
2. **神明代词「祂」**：指森林神明（Ozzy）和天主的大写 `He / Him / His` 统一用 **「祂」**；女巫结社 `covenant` 译 **「巫会」**，和教堂经文的语体区分开。
3. **乡土口语**：年长女性的 `lass / lassie / dearie` 按角色分 **「丫头 / 小丫头 / 乖丫头」**；男童 `lads / laddies` 译 **「小子们」**；骂鸟的 `feathered rat` 译 **「长羽毛的耗子」**（可加修饰，如「长着羽毛的讨厌耗子」）。
4. **内心独白**：伊莉丝括号独白句尾的 `, huh...` 不做机械反问，统一转成 **「……呢…… / ……啊……」** 的自言自语口吻。

## 四、v8 统一规则（收官修订）

### 1. 称谓与敬称

| 原文 | 场合 | 译法 |
| :--- | :--- | :--- |
| `my dear` / `dear` | 长辈对伊莉丝等年轻人 | **「好孩子」**（哀叹语境可作「孩子」） |
| `dearie` | 长辈对年轻姑娘 | **「乖丫头」** |
| `my dears` | 对几个晚辈 | **「孩子们」** |
| `my dear` / `dearie` | 同辈老太太之间 | **「老姐姐」** |
| 第二人称 | 晚辈对长辈、村民对神父 | 平和语境用 **「您」**；争吵、讥讽戏（伊莉丝与威尔玛、贝尔塔、奥蒂莉等）保留「你」；直呼其名的同辈用「你」 |

v7 中两条「待用户定」（`DLG_2_1_OLH_01_006` 的 my dear、`DLG_3_2_VSQ_03_032` 的受话人）已按上表落定：`03_031` 是伊莉丝说的，`03_036` 是她的独白，所以 `03_032` 的 dearie 是对伊莉丝说的。

### 2. 术语与专名

- **星期**：对白一律用「星期X」，Sunday 口语作 **「星期天」**；「主日」只用于「主日弥撒」等礼仪说法；作「周」讲的「礼拜」也改为「星期」。界面上的短标签（周一…周日）不变。
- **festival**：统一为 **「节庆」**（圣瓦尔普加节，不再与「节日」混用）。
- **地点**：viewpoint 是 **「观景台」**（不是基弗伯格峰）；crossroads 是 **「十字路口」**；village square 是 **「村广场」**（地图名同步）；Bedewed Forest of Berries 是 **「缀露浆果林」**（与「陶瓷麦林」同构）。
- **hag-ridden**：完整说法用 **「遭了女巫夜骑的魔祟」**，回声问和讥讽可简作「遭了女巫夜骑？」「还女巫夜骑呢！」。
- **Flocke**（萝丝玛琳的山羊）：代词统一用 **「它」**。

### 3. 口头禅与感叹词

英文角色的口头禅如果每句都照字面译，连着读就很机械。v8 的处理办法：

| 原文 | 处理 |
| :--- | :--- |
| `..., is all` / `that's all` | 「罢了 / 而已 / 嘛」或并入「只是/不过」，不再用「仅此而已」 |
| `you see?` / `you know?`（解释性） | 用句末语气词（嘛/呢/啊）或句首「你看/您瞧」；确实在问对方懂没懂时，才用「明白吧？/你明白吗？」 |
| `that's for certain` / `I'm certain` / `I wager` / `I'd say` | 并入句中（可真是/确实/肯定/八成/我看），只在年长角色唠叨时保留少量「要我说」 |
| `..., that's what!` | 用强调句式或重复，不用「就（是）这么回事」 |
| `X, you say?` | 「你说X？/你是说……X」，不倒装成「X，你是说？」 |
| 句尾 `I suppose` / `I take it` | 「……吧 / 大概……」，不以「，我想/我猜」收尾 |
| `Oh, ...` | 按语气选：叹息、同情用「唉」；慌乱、抱怨用「哎呀」；长辈的欢喜用「哎哟」；轻蔑用「哼」；孩子的惊喜用「哇」；想起来、打招呼、道谢用「啊」；疑惑用「咦」；也可以不译。只有恍然、应答、轻声反问才用「哦」 |

### 4. 句末标点（D5 细则）

- 原文没有省略号的地方，不在「！/？」前加「……」；原文以省略号收尾、话没说完的地方，不加「！」。
- 原文的 `?!` / `!?` 统一译作「？！」。
- 附加问句（`you see?`、`can I?`、独白里的 `huh?`）在英文里是陈述口吻，中文按陈述处理，句末可以用「。」，和第三节第 4 条的独白规则一致。

### 5. 歌词

序曲和终章的角色曲（`SUB_001_*`、`SUB_002_*`）用对齐日文原唱的定稿译词，**锁定不改**。旁白层里英文相同的重复行（`NARR_006`、`NARR_012`）也跟着改成同样的歌词，保证不管从哪个渠道显示，都是同一版。
