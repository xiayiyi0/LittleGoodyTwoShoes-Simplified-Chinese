## 图库结论（2026-11-04 复查）

`GalleryButton.cs` 确实存在（`text.text = "Unlock for " + cost;`、`BuyPicture()`、`"Buy this Image?"`），
但**在正式版里这条路径到不了**，证据三条：

1. **没人给货币**：`ProfileData.CederRoses`（`[JsonProperty]`，存档字段）在整个反编译树里只有
   `GalleryButton` **扣**它（`-= cost`），**没有任何地方加它**。基础货币是「雪松玫瑰 Cedar Rose」
   （道具 `ITM_N_N_06`），但道具系统里没有任何把道具兑换成 `CederRoses` 的代码。
2. **没人打开面板**：全库搜 `Gallery` 只有 `GalleryButton.cs` 自己；没有任何脚本、场景名或菜单项引用它。
   （不排除由 prefab 上的 UnityEvent 打开——静态分析证不了，但也找不到任何入口。）
3. **资产里也没有**：60 个 AssetBundle 全部解压后逐对象搜过（9,376 个对象），
   `Unlock for` / `Buy this Image` / `CederRoses` **0 命中**；
   `data.unity3d`（6.4 GB，压缩容器）裸字节搜同样 0 命中。

`Unlock for 2` / `Buy this Image?` 之所以在译本里，是因为它们属于 **`XUAT_` 遗留层**——
那一层来自早期 XUAT 运行时抓到的上屏串（当年的作者跑过别的构建、或用调试入口打开过），
不是当前正式版里可触发的内容。

**处置**：`Unlock for {0}` →「花{0}解锁」这个模板键**保留**（多 1 个 display 键，不会命中任何东西，
也不可能给玩家看到问题；删掉反而要让 display 回到 25,304 并重打包）。但对外**不再宣称
"修了玩家可见的英文"**——那是错的定性。
