## 已定尺度（详见 `rules.md` §10）

- 显示层冲突按组定级：任一场景显示错意 → 组内需改的行都记 P0；只丢标签、语气偏、同义替换 → P1。≤3 行的组读到就定，≥4 行的组留到 4.5。
- P3：每批 ≤3 条，改动小且明显更好才记。
- 小偏差：写 `minor/<批次号>.jsonl`（`sev` = 小偏差），不占 P3 名额；同键已有 findings 就并进那条 fix。「日安」、town/village 混用只在 summary 归纳。
- 独白 / FLV·PIC 自语里的附加问句（huh?、can I?、isn't it? 等）译成「是吧？/不是吗？/……吧？」→ P2 标点格式（预扫 `P9` 列出，打印里标 `[候:P9]`）。
- v8 口头禅：解释性 you see? 译「你知道吧？」、I wager 译「我敢打赌」、I'd say 以「，我倒觉得」收尾 → P2 翻译腔（备注里有 `[v8口头禅…]` 且是有意保留的除外）。
- 「X, you say?」译成倒装「X，是吗？」「X，你是这个意思」→ P2 翻译腔（按 v8 作「你说X？/您是说……」）；句首 I'm certain / I'll say 生硬直译（「我可十分确定」「我就是这个意思」）→ P2 翻译腔。
- 对白里双重附加问「……吧，不是吗？/……吧，是不是？」→ 小偏差（翻译腔）；孩子央求式「……吧，对不对？」读着自然的不报。
- 「Is that so?」全表 8 处统一作「是吗……」，不逐行改（verdicts 已说明）。
- 对白里解释性 you see? 译成「明白吗？/你明白吧？/你晓得吧？」也按 v8 记 P2；真在确认对方听懂（如串口供时「明白吗？」）不报。
- 备注写明已按 v8 某规则处理、正文却没改到位的（如 `DLG_3_3_VBA_01_013`），按「执行不到位」照常报。
- 标签数目对、但挪到了别的词上（斜体/粗体强调对象变了）→ P2 标签占位符（`CUT_3_3_VSQ_02_011`）；同时混了术语的并入术语问题定级。
- 原文 `...!`/`...?` 整组删省略号（What...? 16 行等）照 §10.3 记小偏差、整组补记；「Is that so?」→「是吗……」8 行统一不改。
- 句尾 I'd say / I wager 译成「，我得说」「，我估摸着」挂在句末 → 同「，我倒觉得」记 P2；「我们 / 咱们」把听话人算进去 → 小偏差。
- 独白里原文没有附加问句、译文却加了「是吧……」之类 → 同 P9 记 P2 标点格式（`DLG_3_4_VIN_02_022`）。
