## 4. 口头禅与感叹词（v8 第四节 3）

| 原文 | 处理 |
| :--- | :--- |
| ..., is all / that's all | 罢了 / 而已 / 嘛，或并入「只是 / 不过」；不用「仅此而已」 |
| you see? / you know?（解释性） | 句末语气词（嘛/呢/啊）或句首「你看 / 您瞧」；真在问懂没懂才用「明白吧？/ 你明白吗？」 |
| that's for certain / I'm certain / I wager / I'd say | 并入句中（可真是/确实/肯定/八成/我看）；年长角色唠叨可少量保留「要我说」 |
| ..., that's what! | 强调句式或重复；不用「就（是）这么回事」 |
| X, you say? | 「你说X？/ 你是说……X」，不倒装成「X，你是说？」 |
| 句尾 I suppose / I take it | 「……吧 / 大概……」，不以「，我想 / 我猜」收尾 |
| Oh, ... | 叹息同情「唉」；慌乱抱怨「哎呀」；长辈欢喜「哎哟」；轻蔑「哼」；孩子惊喜「哇」；想起来、打招呼、道谢「啊」；疑惑「咦」；也可不译。只有恍然、应答、轻声反问才用「哦」 |

## 5. 标点与格式（v8 第四节 4 = D5，及通用规范）

- 全角标点；对白中不应出现半角 `, . ? ! : ; ( ) "`（标签内部、数字、`{0}` 除外）。
- 省略号只用「……」（两个 U+2026）；破折号只用「——」（两个 U+2014）。
- 引号一律「」，『』只用于引号内再套引号（及定案 `『赠礼』`）。
- 原文没有省略号的地方，不在「！/？」前加「……」；原文以省略号收尾、话没说完的地方，不加「！」。
- `?!` / `!?` 统一作「？！」。
- 附加问句（you see?、can I?、独白里的 huh?）在英文里是陈述口吻，中文按陈述处理，句末可用「。」。
- 内心独白：括号用全角（）；伊莉丝独白句尾 `, huh...` 不做机械反问，转成「……呢…… / ……啊……」的自言自语。
- 标签（`<b> <i> <color> <sprite> <shake> <wave> <incr> <size>` 等）、`{0}` 占位符、换行与英文一致。已备注的有意偏离：`<color value="#…">` 归一为 `<color=#…>`；补闭合源文缺失的 `</color>` / `</b>`；`CUT_D_WSN-J_01_003` 补 `<b>祂</b>`。

## 7. 严重度与类别

| 级别 | 含义 |
| :--- | :--- |
| P0 必改 | 中英不对应（串位、张冠李戴）；意思相反；乱码、衍文、截断；漏掉影响剧情或解谜的信息（方向、数量、物品、指代）；标签或占位符损坏；显示层冲突导致某场景显示错台词 |
| P1 应改 | 习语、反讽、双关理解错；说话人/受话人判断错导致人称、称谓错；真名与错叫用反；违反规则书术语；增删改变了信息或语气；跨行衔接断裂（回声问对不上、选项与回应不配对、前后呼应丢失） |
| P2 建议改 | 明显翻译腔、语序别扭；人物语气失真；同场景用词不统一；违反第四节 v8 规则 |
| P3 可选 | 现译可接受但有明显更好的说法；改动小、明显更好时才记，每批最多 3 条 |

类别：串位 / 误译 / 漏译 / 增译 / 衍文 / 人称称谓 / 人名术语 / 衔接 / 分支 / 语气 / 翻译腔 / 标点格式 / 标签占位符 / 显示层冲突 / 源文问题。

## 10. 试跑后确认的尺度（2026-10-22，用户确认）

1. **显示层冲突的级别**：词典里显示的那句意思没错，只是丢了标签或语气偏 → P1；显示出来的意思明显错（如「不买。/不亲。」）→ P0。冲突组内各行的建议必须一致（`validate_fixes.py` 会查）；冲突组的整组裁决留到 4.5。
2. **P3 的量**：保持试跑水平——只在改动小且明显更好时记，每批最多 3 条，412 行试跑记了 3 条。
3. **小偏差也要记**，但单独成册，不占 P0–P3、不占 P3 名额：
   - 写进 `review/minor/<批次号>.jsonl`，字段和 findings 相同（key/sev/cat/fix/why/ctx/conf），`sev` 固定写 `小偏差`，`cat` 用同一套类别（多为 标点格式 / 增译 / 漏译 / 人称称谓 / 语气）；没有小偏差也要建空文件。
   - 范围：不影响理解、也不违反规则书的细小出入——原文 `...!`/`...?`/`...` 的省略号被删或多加、叹号问号句号的增减、叠词/重复/结巴的增删（「等等！等等」、`I'll... I'll` 被并掉）、没有信息量的小增译（「你看！」）、同一对人物在同一场景里你/您来回换、逗号漏标等。
   - 违反 D5 等规则书条文的仍记 P2，不算小偏差。
   - 同一行既有 P0–P3 问题又有小偏差时，把小偏差一并改进 findings 那条的 fix 里，不再单记（一个记录键只能有一条建议）。
   - 不按行记、只在 summary 归纳的风格选择：「日安」（Good day，全表 9 处）、town/village 混用跟着英文走。
